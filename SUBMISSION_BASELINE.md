## 4. Fake / Mock / Stub Implementations Connected to Production Paths

1. **`AssemblySIPProvider` (`backend/src/modules/telephony/index.ts`)**:
   Connected directly to `POST /api/telephony/outbound/initiate`. Simulates SIP carrier connection using deterministic UUID generation and test phone numbers rather than an actual SIP trunk.
2. **`BillingService.reconcilePurchase` (`backend/src/modules/billing/index.ts`)**:
   Connected directly to `POST /api/billing/purchases/reconcile`. Grants credits based on local product catalog validation without verifying purchase tokens with the RevenueCat REST API.
3. **Database Repositories (`calls`, `audit`, `meetings`, `approvals`, `leads`, `company`)**:
   All repositories catch PostgreSQL errors silently and store state in memory. If `DATABASE_URL` is unavailable or invalid, the backend continues running in in-memory mode without raising errors.
4. **Android Data Layer (`android/app/src/main/java/com/webcraft/employee/data/fake/`)**:
   The entire Android application runs against `Fake*` repositories; no network data source exists to toggle to.

## 5. False / Outdated Documentation Claims

1. **Test Suite Count**: `docs/JUDGE_ACCESS.md` and `README.md` claim "142 tests across 18 test suites". Actual current count is **146 tests across 18 suites** (all passing).
2. **Static Plugin Registration**: `README.md` claims `@fastify/static` is registered to serve `public/voice-tester.html`. In reality, `@fastify/static` is neither installed in `package.json` nor registered in `server.ts`; the file is served via an explicit Fastify route (`GET /voice-tester`).
3. **In-Memory Relational Store Claim**: `README.md` claims an "atomic in-memory relational store with identical query interfaces" activates when `DATABASE_URL` is unset. In reality, each module maintains standalone JavaScript Arrays/Maps, and `pg.Pool` connection failures are silently swallowed.
4. **Test Run Duration**: `README.md` claims tests execute in "~1.2s". The actual duration is **~111.7s** because telephony and meeting tests include realistic timer-based simulation delays.
5. **Product Naming**: Inconsistencies persist between "HQ", "Webcraft Employee", "HQ Employee", and "HQ-Employee".
