## 6. npm test Script Bug

The `package.json` test script uses `test/**/*.test.ts` glob which Node 22 does not expand via shell glob:

```
"test": "node --import tsx --test test/**/*.test.ts"
```

This fails with: `Could not find '/home/watcher/Desktop/employee/backend/test/**/*.test.ts'`

All 142 tests pass when files are listed explicitly. This is a **P1 blocker** for judge reproduction.
