## Screen-by-Screen Functionality Matrix

| SCREEN | ROUTE | ENTRY POINT | VIEWMODEL | USE CASE | REPOSITORY | API | BACKEND ROUTE | DATABASE EFFECT | VISIBLE RESULT | ERROR STATE | LOADING STATE | EMPTY STATE | RETRY STATE |
|---|---|---|---|---|---|---|---|---|---|---|---|---|---|
| **Dashboard** | `/dashboard` | `WebcraftNavGraph` (Start) | `DashboardViewModel` | `GetDashboardDataUseCase` | `LeadRepository`, `MeetingRepository`, `BillingRepository` | REST HTTP | `GET /api/leads`, `GET /api/meetings`, `GET /api/billing/wallet` | Reads current active leads, meetings, and wallet balance | Status cards, quick action chips, real wallet credits (no static 45) | Red error banner with retry button | Centered indigo progress spinner | Zero-count cards ("0 Leads", "0 Meetings") | Click retry button re-triggers `refresh()` |
| **Employee** | `/employee` | Bottom Nav / Dashboard "START EMPLOYEE" | `EmployeeViewModel` | `GetEmployeeUseCase`, `VoiceCallRepository` | `EmployeeRepository`, `VoiceCallRepository` | REST HTTP & WebSocket | `GET /api/company/runtime-context`, `GET /api/voice/token`, `POST /api/voice/tools/execute` | Tool calls log audit records; ephemeral sessions created | Live employee role, policy v1.0 badge, real-time call controls, live transcripts, and policy decisions | Error card with message ("Voice connection failed") | Loading indicator while fetching context | Empty transcript feed ("Click Start Call...") | Reset session and tap "Start Voice Call" |
| **Leads** | `/leads` | Bottom Nav / Dashboard Quick Action | `LeadsViewModel` | `GetLeadsUseCase` | `LeadRepository` | REST HTTP | `GET /api/leads` | Queries all company leads (`SELECT * FROM leads`) | Ranked lead cards with qualification badges, scores, and contacts | Full-screen error text | Circular progress indicator | "No leads found. Qualified leads appear here." | Pull-to-refresh or re-navigate triggers fetch |
| **Lead Detail** | `/leads/{leadId}` | Tap Lead Card on Dashboard or Leads | `LeadsViewModel` | `GetLeadDetailUseCase` | `LeadRepository` | REST HTTP | `GET /api/leads/:id`, `PATCH /api/leads/:id/status` | `UPDATE leads SET status = ...` and logs `LEAD_UPDATED` in `audit_events` | Complete lead dossier: business objective, budget, timeline, memory facts, status dropdown | Toast and inline error message | Shimmer / loader placeholder | "Lead not found" message with Back button | Re-enter screen or trigger status update |
| **Meetings** | `/meetings` | Bottom Nav / Dashboard Quick Action | `MeetingsViewModel` | `GetMeetingsUseCase` | `MeetingRepository` | REST HTTP | `GET /api/meetings` | Queries company scheduled meetings (`SELECT * FROM meetings`) | Chronological list of meetings with dates, durations, and status badges | Error message banner | Centered progress spinner | "No meetings scheduled. Use voice or calendar to book." | Re-fetch on screen focus |
| **Company Brain** | `/company_brain` | Bottom Nav / Dashboard Quick Action | `CompanyBrainViewModel` | `GetCompanyBrainUseCase`, Profile/Service/FAQ UseCases | `CompanyBrainRepository` | REST HTTP | `GET /api/company/brain`, `PUT /api/company/profile`, `POST /api/company/services`, `POST /api/company/faqs` | Updates `company_profiles`, `company_services`, `company_faqs` | Tabs for Profile, Services, FAQs, and Policies with live edit dialogs | Save error alert | Tab loading spinner | "No services added" placeholder | Re-open dialog and submit |
| **Billing** | `/billing` | Header Wallet Chip / Dashboard Quick Action | `BillingViewModel` | N/A (Repository direct) | `BillingRepository` | REST HTTP | `GET /api/billing/wallet`, `GET /api/billing/offerings`, `POST /api/billing/reconcile` | Inserts double-entry transaction in `credit_transactions`, updates `credit_wallets` | Real wallet balance (1000 Cr), package purchase cards (Starter, Growth, Scale) | In-app purchase error banner | Loading offerings indicator | "No credit packages available" | "Reconcile Wallet" / retry purchase button |
| **Settings** | `/settings` | Top Bar Settings Icon | `SettingsViewModel` | N/A | N/A | Local / Config | N/A | None | API base URL configuration, diagnostic toggles, version info | Invalid URL warning | Instant | Default configuration loaded | Reset to defaults button |
